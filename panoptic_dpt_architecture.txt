│  ├─ Converts camera poses → geometric tokens                            │
│  └─ Fuses with encoder features                                         │
│                                                                          │
│  Multi-View Transformer (info_sharing)                                  │
│  ├─ Cross-attention between all N views                                 │
│  ├─ Each view "sees" all other views                                    │
│  └─ Output: [final_feat_0, ..., final_feat_N] + intermediates          │
└─────────────────────────────────────────────────────────────────────────┘
                              ↓

                              ↓
              ┌───────────────┴───────────────┐

3D CONSISTENCY LOSSES (MultiViewConsistencyLoss module):
═══════════════════════════════════════════════════════════════════════════

INPUTS TO CONSISTENCY LOSS:
┌─────────────────────────────────────────────────────────────────────────┐
│ From Geometric DPT:          From Panoptic DPT:                         │
│ • depths [N,1,H,W]           • all_view_features:                       │
│ • confidences [N,1,H,W]      │   - res2 [N,B,96,H/4,W/4]               │
│                              │   - res3 [N,B,192,H/8,W/8]              │
│ From Camera Data:            │   - res4 [N,B,384,H/16,W/16]            │
│ • camera_poses [N,4,4]       │   - res5 [N,B,768,H/32,W/32]            │
│ • camera_intrinsics [N,3,3]  │                                         │
│                              │ From Mask2Former (optional):             │
│                              │ • query_embeddings [N,Q,D]               │
│                              │ • pred_masks [N,Q,H,W]                   │
└─────────────────────────────────────────────────────────────────────────┘
              ↓
┌─────────────────────────────────────────────────────────────────────────┐
│ STEP 1: Compute Correspondences (depth-based reprojection)              │
│ ────────────────────────────────────────────────────────────────────────│
│ For each pair (view_i, view_j):                                         │
│   1. Unproject view_i pixels using depth_i → 3D points                  │
│   2. Transform 3D points using camera_pose_i → world coords             │
│   3. Transform world coords using camera_pose_j^-1 → view_j cam coords  │
│   4. Project to view_j using intrinsics_j → pixel coords                │
│   5. Filter by:                                                          │
│      • confidence_i > threshold                                          │
│      • depth_i > 0                                                       │
│      • projected coords in view_j bounds                                 │
│                                                                          │
│ Output: List of valid correspondences                                   │
│   corresp = {src_idx, tgt_idx, src_coords, tgt_coords, valid_mask}     │
└─────────────────────────────────────────────────────────────────────────┘
              ↓
              ├──────────────────┬──────────────────┬──────────────────┐
              ↓                  ↓                  ↓                  ↓
              
┌───────────────────────┐ ┌────────────────────┐ ┌──────────────────────┐
│ LOSS 1: Dense Feature │ │ LOSS 2: Query      │ │ LOSS 3: Mask         │

│                       │ │                    │ │ 2. Compare warped    │

│    Σ conf_i *         │ │ L_query =          │ └──────────────────────┘
